# conveyor-belt (piBrain)

Arduino(`Servo.h`) 컨베이어 벨트 컨트롤러입니다. piBrain에서 시리얼(9600 bps)로 `#모터:값!` 패킷을 보내 제어합니다.

- `m1` (D5): 롤러용 연속회전 서보. 값 -90~+90 → `write(값 + 90)`
- `m2` (D6): 분류용 서보. 값 -90~+90 → `write(값 + 90)`

예: `#m1:10!`, `#m2:-30!`

## 배선 전 확인 사항 (확인 필요)

- **Arduino 보드 모델**: 코드에 명시되어 있지 않습니다.
- **시리얼 연결 방식 / 전압 레벨**: USB 케이블로 연결하면 문제가 없습니다. piBrain GPIO UART(3.3V)와 5V Arduino TX를 직결하면 안 됩니다. 이 경우 레벨 시프터나 분압이 필요합니다.
- **서보 전원**: 서보 2개(연속회전 1 + 일반 1)를 Arduino 5V 핀에서 같이 받으면 기동 전류 때문에 전압이 떨어지고 리셋될 수 있습니다. 서보 모델·정격 전류를 확인한 뒤 별도 5V 전원 사용을 권장합니다. 이 경우 GND는 공통으로 연결합니다.
